# RC Course Finder

ラジコンサーキット、ミニ四駆コース、ゴーカート場を横断検索するUGC対応コース検索サービスです。

## Repository Name

rc-course-finder

## Domain Candidates

- rccourse.jp
- rcmap.jp
- minicourse.jp
- circuitspot.jp

## Features

- RCサーキット・ミニ四駆・ゴーカート場の横断検索
- 屋内外、レンタル、初心者向け、大会ありフィルター
- 営業確認、路面状態、レイアウト変更、閉店情報のUGC投稿
- SEO/AIO/LLMO向けFAQ、即答ブロック、構造化データ
- robots.txt / sitemap.xml / llms.txt
- 走行予約、用品アフィリエイト、大会告知、確認済み掲載、遠征送客の収益導線
